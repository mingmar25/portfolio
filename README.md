# Mingmar Tamang Portfolio

Static portfolio for Mingmar Tamang, based on the supplied portfolio content.

## Run with Docker

```sh
docker compose up -d --build
```

Open <http://localhost:8081>. To use another local port, set `PORTFOLIO_PORT`:

```sh
PORTFOLIO_PORT=8090 docker compose up -d --build
```

Stop the site with `docker compose down`.
